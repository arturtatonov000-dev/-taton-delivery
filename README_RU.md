# ТАТОН — стартовый проект Android

Это исходный проект интерфейса приложения на Expo / React Native. Он содержит:
- зелёно-белый интерфейс;
- демонстрационный каталог и поиск;
- корзину;
- форму заказа с именем, телефоном, селом, адресом и комментарием;
- известные тарифы: Чикола — 150 ₽, Лескен — 500 ₽.

## Важно
Это пока клиентский прототип. SMS-авторизация, серверная база данных, роли владельца/пяти курьеров и реальная отправка заказов в WhatsApp ещё не подключены. Для этого нужны настройки Firebase/серверной части, номер WhatsApp владельца и реальные товары с ценами.

## Запуск
Требуется Node.js и Expo CLI / Expo Go. После установки зависимостей:
1. `npm install`
2. `npx expo start`
3. Открыть проект в Expo Go по QR-коду.

Пакет Android: `ru.taton.delivery`.
